Connect to YouTube, without a paid service.

SignalTube is designed to run within Google’s free daily YouTube API quota. You create your own key, keep it on your computer, and decide when to refresh.

What is the key for?

An API key identifies your Google project when SignalTube requests public channel details and recent uploads. It is not your Google password. SignalTube does not sign into your YouTube account, upload your watch history or change your subscriptions.

Why should this cost nothing?

Google currently provides a default allowance of 10,000 units per day for the ordinary API methods SignalTube uses. SignalTube sets a much smaller 100-unit daily cap of its own. Units measure API requests, not money or videos.

For example, refreshing 10 channels uses up to 20 units the first time, then usually 10 while their channel details are cached. The app shows the estimated cost before you refresh. Google’s quotas reset at midnight Pacific Time.

At the limit, SignalTube stops refreshing. It does not buy more quota or enable billing. Your cached library remains available until its normal data expiry. Opening the app, leaving it in the tray, building a shortlist and saving videos do not call YouTube. Playing a video opens YouTube in your usual browser.

No payment card, Google Cloud free-credit trial, hosting plan or paid AI subscription is part of this setup. Other services you enable and other apps sharing your project are separate. Check your own project’s quota and Google’s current terms. If a setup screen asks you to activate billing, stop and check rather than agreeing.

Set up your key

  1. Create a project. Open Google Cloud Console, sign in and create a dedicated project called SignalTube. Make sure it is selected.

  2. Enable YouTube Data API v3. Under APIs & Services → Library, find and enable that exact API. You do not need YouTube Analytics, Gemini, OAuth or a service account.

  3. Create an API key. Open APIs & Services → Credentials → Create credentials → API key. If asked what data you need, choose Public data.

  4. Restrict the key. Under API restrictions, select Restrict key → YouTube Data API v3, then save. This limits which API can use the key.

    The caller is your local Python app, so website/referrer restrictions will not work. An IP restriction needs your stable public internet address—not 127.0.0.1 or a home-network address. If that is impractical, leave application restrictions unset for the local trial, keep the API restriction, and keep your key private.

  5. Check the daily limit. Under YouTube Data API v3 → Quotas & System Limits, find Queries per day. If editable, lower it to 100 for this dedicated project and verify it saved. If that option is unavailable, SignalTube still enforces its own cap. Do not create extra projects to evade quotas.

  6. Add the key to SignalTube. Right-click its tray icon → Set YouTube API key… and paste into the masked box. In the browser/source edition, run ./run.sh key-add instead. Saving the key does not make a request.

  7. Refresh when ready. Return to your library, check the estimated units, and click Refresh from YouTube. This is when SignalTube contacts Google.

Keep control of your usage and key

The app shows its reserved units beside Refresh. Google Console shows the project’s usage; reporting delays and reserved failed requests can make them differ. Keep one active installation and its quota history. Don’t delete the ledger to reset the allowance or independently refresh multiple copies with the same project.

Your key is stored in an owner-only local file, not in the web page. Keep it out of screenshots, chat, GitHub and URLs. Existing keys are never silently replaced. If exposed, revoke it in Google Console before deliberately replacing the local key; keep your quota history.

Troubleshooting

If the key is rejected, check the selected project, API enablement and restrictions. If the daily limit or cooldown is reached, wait until the time shown in the app. No automatic refresh or retry happens in the background.
